# GUI95 privacy information

Publisher: Stephen Lavelle. Updated 15 October 2026.

GUI95 is a bundled skill and reference collection. It has no publisher-operated server, account system, analytics, advertising, or telemetry. The plugin does not send your prompts, project files, generated code, or personal information to its publisher, and the publisher does not retain those inputs through the plugin.

The host assistant reads the bundled instructions and may work with project files that you authorize it to access. That processing is governed by your assistant provider's privacy policies and your account settings. GUI95 does not add a remote MCP connection or require another service account.

The optional browser demo runs its application logic in your browser. It does not upload drawings or save desktop preferences between reloads. Its Save As command downloads a drawing to your device. The public demo and repository are hosted by GitHub; visits, downloads, and interactions with GitHub are subject to GitHub's own data practices. Links to external reading material open those providers' websites.

If you voluntarily open a public GitHub issue or pull request, the information you include (such as your GitHub username, description, and attachments) is visible to the publisher and other GitHub visitors and is used to discuss and maintain the project. It remains in that public discussion until removed through GitHub's controls or moderation. Do not include private project files, credentials, or sensitive personal information in a public issue. You can edit or remove your contributions using GitHub's available controls.

You can stop using GUI95 by uninstalling the skill or plugin. There is no GUI95 user database or plugin telemetry history for the publisher to delete. For questions about GUI95, use the [project's issue tracker](https://github.com/increpare/gui95/issues).
